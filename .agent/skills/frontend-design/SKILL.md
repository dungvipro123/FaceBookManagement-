# Frontend Design Skill

Adopt the mindset of a design lead at a high-end design studio.
Build distinctive, purposeful frontend user interfaces:
- Dark "command-center" aesthetic with intentional typography, curated color palette (deep blacks, slate grays, neon/amber accents), and high-contrast readable elements.
- Avoid purple-gradient-on-white clichés and generic rounded card templates.
- Glassmorphism panels with subtle border highlights, readable contrast, and smooth transitions.
- Responsive across mobile (375px) and desktop (1440px).
- Respect `prefers-reduced-motion` and include performance degradation fallbacks.
