# WebApp Testing Skill

Guide for automated browser testing using Playwright:
- Reconnaissance then action workflow.
- Validate dynamic elements, canvas renders, form submissions, and SSE streams.
- Capture screenshots at 375px (mobile) and 1440px (desktop).
- Verify graceful degradation when WebGL is disabled or context is lost.
- Ensure all tests use mock servers and mock tokens; never execute destructive tests against live production endpoints.
